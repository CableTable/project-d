As builtLayers panel: + Add is live
Session 7 (2026-10-19). + Add (top right of the Layers list) adds a layer named Layer1, Layer2… (the first free one) that becomes the current layer. Its row has a colour box in place of the swatch and its name in a text box, selected and ready to type over (Enter keeps it; a name that is empty, already used or has a character DXF forbids says why and goes back, with an orange edge on the box). The name and colour stay editable until something is drawn on the layer. One undo step "Add layer"; the layer is saved in the DXF even when empty. Layer 0 stays listed once a layer was added, so it can be made current again. Not on a layout tab.
As builtClose prompt: unsaved tabs
Session 7 (2026-10-19). Closing the window with a dot on any tab opens a small dialog over the page: Save changes to "name"? (one tab) or Save changes to N drawings? with the names listed (five at most), and the buttons Cancel · Don't save · Save (Save is the primary one and has the focus; Esc and a click outside are Cancel). Save runs the usual Save for each tab in turn; a cancelled Save dialog keeps the window open. In a browser the page's own unload warning is used instead; in the exe F5 and Ctrl+R are off while a tab is unsaved.
