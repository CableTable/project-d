Round 11 · Object Manager (TODO 39)

A tree of everything in the open file, layer by layer, like CorelDRAW's Object Manager. Each layer opens to its objects; blocks and groups open to their members. Eye = show / hide, padlock = lock, click a row = select that object on the sheet. Same drawing in both options: bracket-plate.dxf. Two options for where it lives; the tree itself is the same.

Shown on every board: hidden layer, dimmed (Construction) locked object (Line 120.0) and locked layer (Frame) selected row = that object lit on the sheet (Circle Ø40) search box and Show / Locked filters right-click menu

Option A · a tab in the right panel

The right panel gets two tabs: Drawing (everything it has today) and Objects (the tree). Docked, always in the same place, shares the panel's width. Layers stay in Drawing for quick colour and current-layer changes; the Objects tab has the same eye and padlock per layer.

A · layer tree, Circle Ø40 selected, right-click on a row

Pros

  • Fits the app as it is: the panel is already on the right, no new window to lose.
  • Nothing covers the sheet.
  • Simplest to build: one more panel tab.

Cons

  • Shares the panel with Drawing: you cannot see Properties and the tree at once.
  • Fixed width; long labels get cut.
  • On a 1024 px window the tree is short (about 14 rows).

Questions for Rakshith

  • Is hiding a single object saved in the DXF? Today only layers hide and save (layer off). Saving one hidden object would need a mark the other CAD programs may not read. Or it stays on screen only and comes back visible on reopen?
  • Lock: per object (as locked parts today) or only per layer (what AutoCAD does)? Per object is saved in the app's own block of settings, not in the DXF.
  • Should selecting a row in a hidden layer be allowed (it cannot be seen on the sheet)?

Option B · a floating, dockable panel

View → Object Manager (Ctrl+3) opens a panel you can drag anywhere on the sheet area, resize, or snap to the left or right edge (the dashed zone). The right panel keeps showing Drawing, Layers and Properties at the same time. Position is remembered on this PC.

B · floating panel over the sheet, filtered by "circle", right-click on a row

Pros

  • Tree and Properties on screen together: select in the tree, edit in Properties.
  • Can be made tall and wide, or put on a second screen area.
  • Same pattern as the Contour and Auto-nest panels.

Cons

  • It covers part of the sheet until you move it.
  • More to build: drag, resize, docking, remembered position.
  • On a small window it competes with the sheet for room.
